About This Tool

A comprehensive electronic component calculator designed for engineers, technicians, and hobbyists. Calculate resistor, inductor, and capacitor values with color code conversion.

🔴 Resistor Calculator

Convert between color codes and resistance values. Supports 3, 4, and 5-band resistors with tolerance calculation.

🟤 Inductor Calculator

Calculate inductance values from color codes. Supports nH, µH, mH, and H units with multiple band configurations.

🔵 Capacitor Calculator

Convert ceramic capacitor codes to values and vice versa. Supports pF, nF, and µF with tolerance codes.
